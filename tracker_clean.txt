RECONCILIATION WORKFLOW
  monthly process (12 steps)
    1. download all bank/card statements for the month
    2. download upi statements (cred, gpay, amazon pay, paytm)
    3. identify shared expenses vs personal
    4. cross-check people availability dates (who was here)
    5. calculate splits (equal / itemized as needed)
    6. update splitwise app with each shared expense
    7. mark each line item done in this tracker
    8. flag unclear items as 'todo' with what needs checking
    9. get confirmations on whatsapp for disputed/large amounts
    10. update LENDING TRACKER for any money lent or borrowed
    11. update RECURRING SUBSCRIPTIONS section
    12. mark the month as done and archive any receipts
  transaction format
    Date | Description | Amount | Action | Person
  tips
    note out-of-station dates immediately when they happen
    flag unauthorized/unknown transactions same day, don't wait
    track lending separately from regular splits
    weekly review prevents end-of-month backlog
    cross-verify large amounts (> ~₹5,000) on whatsapp
    keep receipts/screenshots for disputed items
